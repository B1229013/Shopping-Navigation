## 備註

- 感知＝伺服器模式 B（部署中的 .env：PERCEPTION_ENABLED=0、OCR_ENABLED=0）：兩階段 VLM（gpt-5.4-mini），目標用中性的「定位」；每張照片只問一次並快取
- 融合權重 DINOv2 : 物件 : 文字 = 1 : 0.1 : 0.3；物件相似度＝字元與語意向量取較大值
- 重播：用快取的 VLM 原始回覆跑目前的伺服器解析程式（未呼叫 VLM）；第 3 階段關；需要重問但沒有快取回覆的呼叫 0 次（當作失敗）
- 答案＝拍照前設的點位標記（eval/data/lab1019_labels.csv）；中點在兩端任一節點都算對，誤差量到中點本身
- +replay：手機 MapPositionEstimator 的 Python 版重播 Sensor Lab 的原始 PDR（入口對齊、每點拍完後用「正確位置」修正一次＝oracle），送出的 map_x/y、dist_since_fix、fix_node 和導航模式相同
- 朝向標註＝拍照當下 cal_yaw 經同一個估計器轉成地圖方向（入口面向賣場＝0°），是推算值
- 位置相同的兩個節點（9 和 24）互相算對
