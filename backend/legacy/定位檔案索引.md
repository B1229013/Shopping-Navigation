# 定位（Localization）檔案索引 — 給同學參考

> 用途：快速找到「定位」相關的程式與資料在哪裡、各自負責什麼。
> 做法、各元件的效果與測試結果請看 [定位方法彙整與測試規劃.md](定位方法彙整與測試規劃.md)。
>
> **一句話現況**：導航後端（`backend/server/`）的定位＝**DINOv2 影像 ＋ 物件名稱 ＋ OCR（1 : 0.1 : 0.3）**，
> 再和手機感測器位置做機率融合。lab1019 單張照片 Top-1 47.6%（`VLM_PASS3=0`：48.1%），帶手機 PDR 63.3%。

---

## 1. 導航時會用到的檔案（每張照片都會跑）

定位是「拍一張照片 → 判斷目前在地圖的哪個節點」。下面的路徑都相對於 `backend/`。

| 檔案 | 角色 | 關鍵進入點 |
|------|------|-----------|
| [server/server.py](../server/server.py) | 串接點：照片 → VLM 感知 → 定位 → 路線 | `_run_early_localization()`、`_server_dino_evidence()` |
| [server/locate_fusion.py](../server/locate_fusion.py) | **主線**：伺服器端影像證據（DINOv2 ＋ 物件 ＋ OCR，`W_V, W_N, W_O = 1, 0.1, 0.3`） | `server_image_evidence()`、`best_photo_per_node()`、`build_fusion_index()` |
| [server/dino_embed.py](../server/dino_embed.py) | DINOv2 影像向量（`facebook/dinov2-base`，第一次用才載入；沒裝 torch／transformers 時回 None） | `embed_image()`、`available()` |
| [server/visual_localization.py](../server/visual_localization.py) | 定位主函式：組合影像證據、走道吊牌、感測器；物件名稱比對（中英名稱、語意向量、稀有度）；沒有 DINOv2 時的 4×4 格子比對；VLM 重排序 | `localize()`、`match_by_grid()`、`ensure_label_embeddings()`、`vlm_rerank()` |
| [server/loc_fusion.py](../server/loc_fusion.py) | 影像證據 × 手機感測器位置 → 每個節點的機率 | `fuse_v2()`、`sensor_sigma()`、`image_weight()` |
| [server/aisle_signs.py](../server/aisle_signs.py) | 走道吊牌號碼 → 可能的節點（只用在 `AISLE_SIGN_PLACES`） | `sign_evidence()`、`numbers_in_items()` |
| [server/object_relations.py](../server/object_relations.py) | 物件上下左右排列一致的分數（`LOC_RELATION_WEIGHT`） | `relation_score()` |
| [server/heading.py](../server/heading.py) | 依最像的方向照片估計使用者朝向 | `estimate_heading()`、`best_matching_slot()` |
| [server/config.py](../server/config.py) | 所有定位設定（`LOC_*`、`GRID_N`、`EMBEDDING_*`、`DINO_SIDECAR_PATH`…） | — |

**上游（提供定位輸入）**

| 檔案 | 提供什麼 |
|------|---------|
| [server/vlm.py](../server/vlm.py) · [server/prompts.py](../server/prompts.py) | VLM 讀出的物件、商品名、OCR 文字、店內區域（預設由 VLM 讀，不用本機模型） |
| [server/perception.py](../server/perception.py) · [server/ocr.py](../server/ocr.py) | 本機 GroundingDINO／EasyOCR（`PERCEPTION_ENABLED`、`OCR_ENABLED`，預設關） |
| [server/neo4j_client.py](../server/neo4j_client.py) | 店家地圖：`Waypoint`、四方向 `DirPhoto`（含 DINOv2 向量）、`Object`、`WALKWAY`、`ADJACENT` |

## 5. 看定位怎麼運作，最快路徑

1. 讀 [定位方法彙整與測試規劃.md](定位方法彙整與測試規劃.md) 第 1 節，了解每個訊號的角色。
2. 看 [server/server.py](../server/server.py) 的 `_run_early_localization()`：照片進來後依序組出哪些證據。
3. 看 [server/locate_fusion.py](../server/locate_fusion.py) 的 `server_image_evidence()` 與
   [server/loc_fusion.py](../server/loc_fusion.py) 的 `fuse_v2()`：影像證據怎麼算、怎麼和感測器合併。
4. 想重現數字：`cd backend`，`python -m eval.image_only --set lab1019 --perception vlm --vlm-replay`
   （需要照片與 VLM 快取，見 [eval/README.md](../eval/README.md)）。
